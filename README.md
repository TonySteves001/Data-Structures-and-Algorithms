
# Data Structures & Algorithms

> Teaching my brain to stop choosing the most complicated way to solve a problem.

Welcome to my Data Structures and Algorithms workspace. This repository contains **LeetCode solutions and practical projects** focused on exploring data structures, algorithmic techniques, and problem-solving approaches.

The focus is on understanding how data structures and algorithms work, analyzing their time and space complexity, and applying them to solve problems efficiently.

## What's Inside?

| Directory | Description |
|---|---|
| `leetcode/` | Solutions to algorithmic problems from LeetCode, organized by topic |
| `projects/` | Practical projects demonstrating the application of data structures and algorithms |

## Problem-Solving Approach

For each LeetCode problem, I aim to document:

1. **Problem:** The problem statement and LeetCode source.
2. **Approach:** The reasoning behind the chosen solution.
3. **Implementation:** The code used to solve the problem.
4. **Time Complexity:** Analysis of the algorithm's execution time.
5. **Space Complexity:** Analysis of the additional memory used.

## Philosophy

Writing a solution that works is the beginning.

Understanding its complexity, recognizing alternative approaches, and knowing when to apply a particular data structure or algorithm is the real objective.
